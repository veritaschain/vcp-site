このページで確認できること

VeraSnapアプリ、受領側のVerify SDK、公開Explorer、公式サイト・問い合わせを、別々の処理系として整理します。法人・保険会社の導入担当者が、何をどこへ渡し、誰が保管・削除を管理するかを確認するための案内です。

確認範囲：2026年11月28日に公開文書と参照版のソースを照合しました。アプリ配布バイナリの通信測定、運用環境の監査、保存期間・保存国の実測は行っていません。「公開資料の説明」「ソースで確認」「導入時に要確認」を区別します。

本ページは解説であり、プライバシーポリシー、アプリの利用条件、個別契約を置き換えません。VSOはVeritasChain株式会社が運営する仕様策定活動です。認証取得や独立監査の証明として使用するページではありません。

データが通る経路を先に決める

  1. 撮影端末：写真・動画と対応する証明を作成。タイムスタンプ要求は外部TSAへの通信を伴います。
  2. 提出：利用者が共有・エクスポートした原本と証明を、組織が承認した受領経路へ渡します。メール、業務システム、クラウド保管の条件は、その経路で別に決まります。
  3. 受領側：組織が管理する環境でVerify SDKへ証明・必要な写真・鍵台帳・信頼設定を渡し、結果を保存します。
  4. 判断：技術結果と業務判断を別に記録。原本、結果、提出者との対応表の閲覧権限・保存期間・削除手順を定めます。

これは導入を検討するための経路例です。組織向けCapture SDKは設計段階であり、この経路を実装済みの顧客導入として示していません。アプリ・SDKの役割、原本を受領する手順を合わせて確認してください。

公開Explorer：合成データと接続先

ソースで確認：参照した公開Explorerのエントリーは合成イベントとSDK Evidence Demoを案内します。Evidence Demoは、設定されたveritaschain-evidence-demo.kamimura0000.chatgpt.siteのAPIへ、ケース一覧と選択した合成ケースの検証結果を取得するリクエストを送ります。公開ページの読み込みではホスティングやフォント配信への通常の通信も発生します。Public Explorer — deployed entry and external resource configuration Public Explorer — selected bundle, API requests and local storage

同梱APIクライアントには、APIキーを設定した場合にブラウザーのlocalStorageへ保存し、APIリクエストへ付ける処理があります。これを暗号化された秘密保管庫とは扱いません。公開デモは合成データで利用し、業務用認証情報や顧客資料の受領窓口として使用しないでください。

未確認：API・配信事業者のログ保存期間、実際の保存国、削除完了の運用証拠。このページのソース確認は、API運用環境を監査した結果ではありません。デモの表示・取得成功も、外部アンカーの完全検証や独立再現を意味しません。

このAPIキー設定機能は、Evidence Demoの取得処理とは別の同梱クライアントに属します。機能の存在を確認したもので、今回APIキーを登録・送信したわけではありません。

公式サイトと問い合わせの通信

公式サイトの公開ポリシーは、ホスティング、外部アセット、問い合わせ送信、任意のアクセス解析を分けて説明しています。Formspreeを使うフォームは入力項目を同サービスへ送り、メールリンクは利用者のメール環境を開きます。VSO website privacy policy — analytics and service providers

ソースで確認：VSOの共通解析ローダーは、解析への同意後にGoogle Analyticsのタグを読み込みます。URLからフラグメントと許可対象外のクエリを除き、指定したキャンペーン項目のみを許可します。問い合わせ本文を独自イベントのパラメーターへコピーしません。メールリンクのクリックは問い合わせ到達の確認ではありません。VSO website analytics — consent and URL filtering implementation

同意を拒否しても、ページ・画像・フォント等を配信する通信は残ります。個別ページや外部リンク先の処理を、この解析ローダーの制御と同一視しません。
