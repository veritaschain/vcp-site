更正记录

VSO以新增日期记录的方式更正公开表述，而不悄然改写历史。本页按日期从新到旧列出规范、仓库README和网站的更正，并链接至各项更改记录。带日期的公告和博客文章保留为当时的记录；受影响的内容附有说明。既有记录的中文译文于2026年11月1日补充，原始更正日期不变。

  1. 2026-11-01

    对齐各语言的公开说明、认证提供状态与AILEX关系披露

    日文和中文首页现与英文一致，邀请对公开规范提出技术意见。关于及公司页面将VSO说明为由VeritasChain株式会社运营的技术规范开发倡议，并区分中立性目标、方案规则与当前独立性及认证提供状态。页面链接至既有披露：没有登记的独立CAB，原有申请程序不生效。三个语言版本的VAP-LAP页说明AILEX LLC与VSO运营公司拥有共同代表人，以及草案编辑者的AILEX/VSO所属。所有以往更正均新增中文译文，保留原有日期和日英记录。这些修改不采纳技术提案，也不证明独立验证已成立。

    记录： Source history Certification status AILEX reference disclosure

  2. 2026-10-28

    更正独立性、“数学上不可恢复”、生产环境和RFC 6962相关表述

    法律信息页的“司法管辖区独立性”卡片改为“司法管辖区中立性”，并说明这是设计目标。VAP-AT页面不再称角色分离模型能确保独立性：唯一登记的CAB并不独立于方案所有者。VSO政策页改题为“中立性、运营结构与非背书”，不再将独立性列为VSO的原则；VC-Certified被说明为CAB对技术符合性的评定，而不是合规证明，并注明CAB的状态。中文IAP页不再称认证由独立机构执行，CAB登记页将技术能力列为要求。加密销毁不再被描述为使数据“数学上不可恢复”或“不可恢复”。VCC、What is VCP和Explorer API页面各语言版撤下了符合RFC 6962的主张。英文和中文VC-Certified FAQ的隐私答复与日文一致。带日期的公告、博客和10月26日公告保留原文并附更正或说明，包括曾将第一方概念验证称为生产级的首页卡片。中文首页中将“类似生产环境”译为“生产环境”的卡片也已更正。

    记录： vcp-site #156

  3. 2026-10-28

    撤下未经确认的公司成立日期；申请页显示CAB状态；VeraSnap不再被称为符合CPP

    2026年10月20日至21日起，公司、说明、媒体和VSO页面曾公布VeritasChain株式会社的成立日期。该日期尚未与商业登记证明核实，因此在核实前从正文和结构化数据撤下。VSO活动开始日期不变。VC-Certified申请页现在在费用旁说明：唯一登记的CAB是VeritasChain株式会社，且不独立于方案所有者。VeraSnap页面不再称该应用符合CPP：它是实现CPP v1.4的第一方应用，未进行独立符合性评定，CPP v1.4与VAP v1.2的映射也尚未发布。

    记录： vcp-site #154

  4. 2026-10-26

    10月25日语言对齐的后续更正：中立性、CAB里程碑和FAQ翻译

    10月25日的记录称法律信息页已不再将VSO描述为独立组织，但当时第3节仍名为“VSO独立性政策”。该节现改为“VSO中立性政策”，链接公开的中立性机制并加入角色说明。日英中VC-Certified FAQ的结构化数据也不再将VSO描述为独立机构。VAP-AT路线图将批准首家独立于方案所有者的CAB列为计划里程碑（已有经VSO批准但不独立的CAB），国家认可层也标为计划。日文和中文FAQ不再称加密销毁能使数据数学上不可恢复。角色分离“防止付费通过”的表述改为“旨在防止”。FAQ将认证说明为CAB对技术符合性的评定，中文页面称VC-Certified为符合性认证。IAP状态在每种语言中统一用词。10月25日的原记录保留。

    记录： vcp-site #129

  5. 2026-10-26

    明确RTA验证范围、选定记录与审阅入口

    更新了日英中RTA公告和入口，区分第一方CI与独立复现、选定原始JSON副本与完整制品保留，以及RTA审阅与另行提供的VAP OS-gate工具包。验证FAQ和Silver级参考说明已与实际旧版验证器一致；历史公告保留原文并附说明。实验性扩展仍未采纳，独立复现尚未成立。未改变规范性要求、实现、签名证据、固定分发文件或K3材料。

    记录： VCP RTA / VSO RTA PR #17 RTA PR #18

  6. 2026-10-26

    区分研究提案、SDK发布状态与未解决的规范问题

    新增10月26日的日英中研究更新，介绍VCP PR #16经审阅的结果和局限。明确vcp-sdk v0.1.0是在GitHub发布的第一方预发布版本，不是PyPI/npm发行包，也不是vcp-sdk-spec的实现。区分现行规范、实验候选schema和此前固定的VAP复现工具包，并保留未采纳、未成立第三方独立复现的说明。网站同时纳入10月25日记录的跨语言更正。本次更新不采纳规范性修复，也不主张完全符合。

    记录： Research update VCP PR #16 Site PR #116

  7. 2026-10-25

    对齐英文、日文和中文页面

    已将只在一种语言完成的更正同步到其他语言，并将其余常设页面与VAP v1.2登记状态和当前披露对齐。合格评定机构称为“经VSO批准”；CAB独立性被说明为要求，而运营VSO的唯一登记CAB不满足该要求。法律信息页不再将VSO称为独立组织。过时的Internet-Draft版本被替换为现行版本。VCP Explorer被描述为使用示例数据的演示，并移除了零知识证明、“军用级”“数学上可验证”和预防危机的主张。VAP页面将PrevHash列为可选、ML-DSA列为实验性；中文版列出全部8个领域，补充实现状态，并将VAP-GAM标为构想而非VSO配置文件。更多VCP页面增加了2026年10月24日完整性审查说明。带日期的公告和文章未改写，仅在另一语言已有注记时补齐。

    记录： Site changes

  8. 2026-10-25

    VeraSnap是VeritasChain株式会社的应用，而非VSO的应用

    2026年4月13日的公告将VeraSnap称为“our production cryptographic evidence capture app”。VeraSnap属于运营VSO的VeritasChain株式会社，不是VSO规范；应用商店上架也不表示符合VAP或CPP。英文和中文公告下方已加入日期注记，公告原文保留。

    记录： vcp-site #111

  9. 2026-10-24

    撤回付费合同数量

    此前公布VeritasChain株式会社与欧洲机构订有10份付费服务合同的数量，尚未通过原始记录核对得到证实。核查完成前，已从VAP、VCP、CAP、CPP仓库及本网站撤下该主张。这不表示合同数量为零，也不提出替代数量。

    记录： Dated correction and counting criteria vap-spec #15 vap-spec #20 vcp-site #100 vcp-spec #5 cap-spec #2 cpp-spec #1

  10. 2026-10-24

    监管机构提交数量正在复核

    首页的“50个司法管辖区、67家监管机构”不再作为当前数量展示。名单包含非监管机构条目、占位项、重复项和已不存在的机构。过去带日期的监管机构数量公告予以保留，并注明总数仍在复核。

    记录： vcp-site #102 vcp-site #104

  11. 2026-10-24

    VCP与VAP v1.2的对齐正在审查

    VAP §10.4不再将VCP v1.1和v1.2记录为完全符合VAP v1.2。VCP v1.2的Merkle构造和审计路径示例与该规范自身的RFC 6962要求冲突；仅签署根哈希的AnchorRecord无法认证附带的数量、端点或策略元数据。两份完整性层草案作为未采纳的讨论文档公开，并非已发布勘误。

    记录： vap-spec #18 vap-spec #19 vcp-spec #5 vcp-spec #3 vcp-spec #4

  12. 2026-10-24

    将VCP状态与跨方表述列入已知问题

    VCP v1.2已知问题列表现已记录：§1.1将VCP称为“a global standard specification”并称其“establishes truth”；§5.6（VCP-XREF）使用保证及防止争议的表述。规范正文未改变，这些是勘误候选项。

    记录： vcp-spec #7

  13. 2026-10-24

    移除面向特定公司的提案页

    本网站移除了写给具名公司的页面。部分页面描述VC-Certified方案中的独占地位，以及由评定机构解释标准的安排，并非对方案本身的说明。现在若此类措辞再次出现，测试会失败。

    记录： vcp-site #105

  14. 2026-10-24

    合格评定机构为“批准”而非“认可”

    ISO/IEC 17000:2020将认可（accreditation）定义为涉及合格评定机构的第三方证明。VSO在VC-Certified方案下指定CAB属于批准，网站现采用相应表述。唯一列出的CAB公司提供VSO的运营基础，并不独立于方案所有者。

    记录： vcp-site #106

  15. 2026-10-24

    使命表述与VAP §1.6保持一致

    公司和交易所页面不再称VCP能建立“数学上可验证的真相”或“密码学上可验证的真相”。现改为说明第三方可验证记录是否被更改或在锚定后遗漏；记录可验证并不证明决策正确。

    记录： vcp-site #104

  16. 2026-10-22

    记录： Organisation profile change
