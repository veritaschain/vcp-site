VSO、事案・動向レビュー10件と固定版デモの既知問題を追記

11月13日にマージされたサイトの出典レビュー更新と、VAP相互運用デモの配布状況・既知問題の文書更新を反映しました。リリース説明欄にも日付付きの注意書きを追加しています。

実験的拡張は未採択、第三者による独立再現は未成立です。今回の出典照合・合成データの観察・CIは自社による確認です。マージやCIの成功は、規範への完全適合、正式採択、認証、本番適合を示しません。

1. 事案・動向の出典レビュー10件を追加

サイトPR #224でレビュー10件を追加し、一覧は計64件になりました。内訳は登録済み19件、出典確認済み・登録待ち45件です。今回の10件は後者であり、「新たな確定事案10件」や「登録済み64件」を意味しません。

レビューには事件以外の業界動向も含みます。一次資料と二次報道、主張と反論、未確認事項を分け、訂正履歴とVAPの適用限界の例を更新しました。原資料を直接確認できない部分や、原因・影響が確定していない部分は、確認済みの事実として扱いません。独立した第三者レビューを示すものでもありません。

2. 相互運用デモv0.2.0の公開記録と既知問題を明確化

VAP PR #70は文書3ファイルの更新です。実験用プレリリースは11月8日12:09 JSTに公開済みで、11月7日の「準備中・未公開」という文書は当時の記録として残しています。固定タグとZIPの元コミットは cbd4502 のままです。

固定版の検証器には、Ed25519入力をバックエンド検証前に明示的に検査する処理がありません。呼び出し側が小位数の役割鍵を含む差し替えられた信頼ファイルを受け入れた場合、記録された改変パックは Python cryptography 50.0.2／Node 22.23.4 で7検査を通過しました。一方、リリース時のNode 24.22.1と、元の demo-trust.json を使う場合は拒否されます。条件と実行環境に依存する自社の合成試験の観察です。

信頼ファイルを差し替えられる相手は通常の鍵でも署名できるため、信頼ファイル自体の真正性確認が別途必要です。元の信頼ファイルや、すべての実行環境で同じ問題が成立すると主張するものではありません。

入力検査の修正はPR #68でmainに取り込み済みですが、固定タグ・固定ZIP・当初の32テストの記録には含まれません。今回変更したのは公開説明のみで、タグ・5つの配布ファイル・チェックサム・過去の実行証拠は維持しています。新しいZIPや代替リリースの公開を意味しません。結果を報告するときは実装コミットを固定してください。
