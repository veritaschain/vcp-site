2. Clarifying demo 0.2.0 publication and the known issue

VAP PR #70 updates three documentation files. The experimental prerelease was published on 8 November at 03:09 UTC (12:09 JST). The 7 November preparation text is retained as a historical record. The fixed tag and source ZIP remain at cbd4502.

The tagged verifiers do not explicitly screen Ed25519 inputs before backend verification. If a caller accepts a substituted trust file containing small-order role keys, the recorded altered pack passes all seven checks under Python cryptography 50.0.2 and Node 22.23.4. Node 24.22.1, the release toolchain, rejects it; the original demo-trust.json also rejects that pack. This is a conditional, backend-dependent first-party observation using synthetic inputs.

A party able to substitute trust can also sign with ordinary keys, so the trust file needs separate authentication in every case. This is not a claim that the original trust file or every environment accepts the altered pack.

PR #68 merged the explicit input policy into main. It is absent from the fixed tag, fixed ZIP and original 32-test record. This update changes the public explanation only: the tag, all five assets, checksums and historical execution evidence are retained. No replacement ZIP or new release is announced. Reports must pin the implementation commit.
