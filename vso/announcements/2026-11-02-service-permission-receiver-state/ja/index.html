VSO、サービス許可の再確認と受取側の証拠履歴に関する研究更新5件を公開

11月1日にマージされたEvidect #30–#34について、11月2日に公開ソースとCIログを確認しました。サービス側の許可、保存レポートの受取側検証、基準記録の期限・世代・鍵失効、受取側の巻き戻し検出を扱う合成実験です。このお知らせのために実験を再実行したものではありません。

研究段階 — 未採択・独立再現未成立

実験的拡張は未採択、第三者による独立再現は未成立です。自社CIと保存証拠の再検証は、独立した新規実行、正式採択、完全適合、本番保証、認証とは区別します。別プロセス・別データベース・別署名鍵も、それだけで運営上の独立性を示しません。

1. #30：利用者の委任とサービス側の許可を別に確認

既存の模擬認可ゲートの外側で、利用者の委任と現在のサービス許可の両方を確認します。提供者・モデル・送信先・経路を要求に結び付け、代替経路や非AI処理へ進む場合も個別の要求・承認を必要とします。固定10ケースは合成ラベルと管理下のメモリー内ツールを使う実験であり、実際の銀行・モデルへの接続や事業者の許諾確認ではありません。整合する偽の観測を試験鍵で再署名する負例も追加しました。元の基準記録は拒否しますが、新しい整合する基準記録まで別途採用すると限定的な整合判定が通り得るため、署名だけで観測の真実性は証明できません。#29で将来候補として記録した3論点に対する、後日の限定的な実装です。

変更・対象コミット: evidect-site PR #30 · 4e41e0a014d2989ff22029ccd3aca5d38b0b876d · 自社CI記録

2. #31：保存した10ケースのレポートを受取側で再検証

受取側が選ぶ信頼鍵・チェックポイントに対して署名付き受領証を検証し、元レポートのサイズとSHA-256を照合します。保存済みの試行順序、経路、判定、集計を検査しますが、元の操作は再実行しません。元の要求・承認、当時の委任・サービス許可、要求と経路の結び付け、nonceの利用はNOT_REVERIFIEDのままです。local_status: VALIDは保存内容の限定的な整合であり、安全性の合格ではありません。総合結果は、既知の不正・不一致を除きINDETERMINATEです。デモの基準記録は1時間で期限切れとなり、CI成果物の14日保持とは別です。

変更・対象コミット: evidect-site PR #31 · eebb1f067da6fa596cb14320010cc0e16c2047c5 · 自社CI記録

3. #32：検証時点と基準記録の識別情報を結果に残す

8ケースと10ケースの受取側レポートに、共通の評価時刻、チェックポイントの正規化SHA-256識別子、有効期限を記録します。期限ちょうどの境界でも有効扱いせず、既知の不一致（INVALID）と信頼設定の期限切れ（INDETERMINATE）を区別します。署名済み入力の形式は維持し、結果は未署名の自社実験レポートです。ローカル時計やチェックポイントのハッシュは、第三者の時刻証明や独立した信頼の根拠にはなりません。

変更・対象コミット: evidect-site PR #32 · c6c8d0bd0c3b3da4e3c542a8bf9d0508c6532678 · 自社CI記録

4. #33：受取側が世代履歴と鍵の失効を保持

任意の別実験として、受取側が明示的に用意・採用したSQLiteの状態に、ストリームごとの世代の到達点とローカルな鍵失効を保存します。古い世代や同世代の矛盾、失効鍵による更新を拒否し、検証途中の状態変更も再確認します。欠落・破損・ロックされた状態を暗黙に作り直して成功扱いにはしません。ただし、権限を持つ者がデータベース全体を以前の版へ戻すと、このローカル保護は回避できます。これは負例で示した限界であり、巻き戻し不能な保存や外部失効機関の実装ではありません。

変更・対象コミット: evidect-site PR #33 · 51bfeb90197af7eb0a565b2da7a069aea545d281 · 自社CI記録

5. #34：別の保存状態との照合で受取側だけの巻き戻しを検出

受取側が毎回作る256ビットのチャレンジを、対象ストリームと配送物・レポートのダイジェストに結び付け、別のSQLite保存状態とEd25519鍵による署名応答を照合します。受取側が立会側の保存状態より古い場合、同世代の矛盾、保持された鍵失効、応答の再利用、鍵の不一致などを拒否します。立会側が遅れている・利用不能な場合も成功へ切り替えません。通信は同じホストの別子プロセスを使う合成実験で、独立運営された遠隔サービスではありません。両方の保存状態を戻す負例では、ローカルに整合しても総合結果はINDETERMINATEのままです。立会側の侵害、両保存状態の巻き戻し、応答後の変更、立会鍵の失効、認証されたネットワーク通信は保証範囲外です。

変更・対象コミット: evidect-site PR #34 · eeeacf7effc8103276106dcf606b2bafb7349081 · 自社CI記録

最新の自社CI：各OSで306テスト成功

マージ済みコミットeeeacf7のCIログで、Ubuntu 24.04とmacOS 15のそれぞれ306テスト成功を確認しました。内訳は#34の追加44件（契約32＋結合12）と既存262件です。Node.js 22系・Python 3.12を使用し、両OSの件数は合算しません。契約試験には明示された代替部品があり、結合試験では実際の署名付き受領証、既存の8／10ケース生成処理、2つのSQLiteとローカル子プロセスを使用します。別案の#35は未マージで閉じられており、その試験結果をこの版の根拠として混ぜません。
