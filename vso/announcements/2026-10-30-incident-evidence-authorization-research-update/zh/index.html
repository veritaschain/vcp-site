VCP / VSO · 公告 · 2026年10月30日

VSO发布事件证据、受控上传与执行授权的研究更新

VSO将VAP PR #30、#31、#32及Evidect PR #20、#21纳入公开信息。已记录证据的评估、受控路径的上传和合成操作的执行授权分别作为独立研究对象。以下为对应固定版本的第一方GitHub CI记录。

研究状态：尚未采纳，独立复现尚未成立

提案与实验性扩展仍未获采纳，第三方独立复现尚未成立。合并或第一方CI成功不代表正式采纳、VCP/VAP完全符合性、生产安全性、认证或独立外部锚定。多个操作系统或Python版本的CI仍属于第一方检查。

1. VAP PR #30：事件证据关联提案

这份信息性提案涉及传输授权与观测到的发送、限定范围的删除证据、AI使用披露与发布内容之间的关联。运行策略、验证策略和发布策略分别处理。提案定义了23个合成验收场景；此阶段的23项不代表已成功执行。正式提案编号与目标版本尚未决定，VAP v1.2.0 Draft 3规范正文保持不变。

变更与目标版本: vap-spec PR #30 · ff759c9

2. VAP PR #31：离线证据评估实验

实际执行Ed25519签名验证与RFC 8785规范化，并核对由评估者另行选择的信任配置、目标、工作流和截止时间。真实性、适用性、覆盖范围、许可及结果分别输出。第一方Python 3.12／3.14 CI中，20个测试方法通过，23/23场景的各预期判定字段一致。即使发布证据为正向，结果仍是REVIEW，而非自动发布许可。评估器本身不采集实际发送字节，也不连接生产系统。

变更与目标版本: vap-spec PR #31 · 590df2e · 第一方CI运行记录

3. VAP PR #32：测量实际字节的本地上传实验

实验仅使用固定回环HTTP目标：确定不可变的发送字节、将意图持久记录到SQLite、重新检查授权，再由独立接收进程测量字节并签署限定范围的试验回执。合并后的第一方Python 3.12／3.14 CI中，39个测试方法通过且无跳过，17/17上传场景与17/17导出证据复查符合预期。尝试、正文发送、接收观测、回执验证与结果保存分开记录。UL-14刻意展示绕过门控直接调用成功；符合该预期不代表阻止绕过成功。进程分离不等于操作系统权限隔离，同一主机管理员控制所有角色。SQLite记录不是独立锚定或防篡改存储。现有评估器的remote_outcome: UNKNOWN仍保留，并与试验回执区分。

变更与目标版本: vap-spec PR #32 · d1f1441 · 第一方CI运行记录

4. Evidect PR #20：合成操作的执行授权门控

通过实际Ed25519检查，将请求及单独批准与参数、目标、单次标识及有效期绑定，并在执行前重新检查当前策略。目标仅是内存中添加标记的无害模拟操作。37项测试通过，覆盖18个场景：16项拒绝、1项正常允许、1项部分失败；部分失败保留已观测或可能的影响并拒绝重试。结果来自Ubuntu／macOS第一方CI。请求签名与输出报告签名不同，报告及观察回执未签名，同进程观察者不属于独立见证人。

变更与目标版本: evidect-site PR #20 · 3b121d0 · 第一方CI运行记录

5. Evidect PR #21：可选SQLite重放防护

保留默认内存方式，新增在模拟工具调用前预留单次标识的可选SQLite适配器。存储故障不会触发自动回退或重试。新增33项与保留37项合计70项，为该门控范围的测试数量。四个实际进程场景验证重启后拒绝重放、四进程竞争仅调用一次、部分失败后消耗标识，以及意图提交后执行前强制终止再重试被拒绝。Ubuntu／macOS第一方CI成功。前提是同一个受保护的本地数据库，不保证分布式运行、数据库历史回滚防护、恶意管理员防护或断电行为。生产控制与法规符合性的NOT_ASSESSED、实测基线的BASELINE_REQUIRED保持不变。

变更与目标版本: evidect-site PR #21 · eda471c · 第一方CI运行记录

保留历史记录，分别计算测试数量

各项数量对应不同对象，不作总计。20个方法与23个场景、39个方法与17个上传案例也属于不同计数。10月29日SDK／Explorer／Evidect文章、10月28日SDK记录（Python 306项／TypeScript 140项）、10月27日Explorer记录（API 159项／GUI 26项）、VAP-LAP介绍与固定研究包均保留为当时记录。本次仅增加网站说明，不改变现行规范、模式定义、现有实现、已签名数据、固定配发文件或K3。
