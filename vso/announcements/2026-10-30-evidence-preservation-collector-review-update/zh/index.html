VSO更新研究证据保存、复查与指南说明

本次补充介绍截至2026年10月30日18:25 JST合并的八项更新：VAP PR #33至#38，以及VCP Conformance Guide PR #3、#4。此前同日发布的五项记录保留。实际本地操作、已保存证据复查与文档映射分别说明，并链接对应版本和第一方CI。

研究状态：尚未采纳，独立复现尚未成立

提案及实验性扩展仍未获采纳，第三方独立复现尚未成立。Python 3.12／3.14第一方CI通过、已保存证据复查及自动双语报告，不等于独立新执行、人工评审、规范采纳、完全符合性、生产保证或认证。本地实验由同一管理者控制环境、测试密钥及各角色。

1. VAP #33：关联发布内容、披露与评审授权

本地实验将编辑历史、生成的HTML、AI使用披露和单独的限定范围授权绑定，执行前持久记录并重新检查，随后执行一次发布和读回。第一方CI通过45个测试方法、18/18文件操作场景及18/18保存证据复查。AI使用标记和评审密钥均为合成数据，不代表真实AI服务或独立人工评审。门控外仍可写入，不证明操作系统权限隔离或所有路径控制。现有评估器的发布判定仍为REVIEW。

变更及目标版本: vap-spec PR #33 · 4d98e9531751f5a5c8e12550fab81eb0ee4e7592 · 第一方CI记录

2. VAP #34：限定范围的本地删除证据

针对一个合成本地对象，检查签名请求、版本、范围、期限、事前记录、删除、对象不在场及签名完成证据。54个测试方法、18个文件操作场景及18项导出证据复查通过。保留副本、打开的文件句柄及重新创建的案例说明：命名空间删除不等于普遍消除。不证明远程服务删除、介质清除或所有副本消失；范围外结果保持UNKNOWN。

变更及目标版本: vap-spec PR #34 · b72bbf05c912f5b87560f4c809298c7bbcaf05e4 · 第一方CI记录

3. VAP #35：保存53例原始证据和离线复查包

保存上传17例、发布18例、删除18例的原始证据、摘要及来源记录，并提供含固定源代码的离线复查包。29个测试方法及53/53已保存案例复查通过。归档哈希须与归档外可信值核对。这是既有证据复查，不是每项操作的新执行，也不证明执行者诚实。10月24日固定研究包保持不变。

变更及目标版本: vap-spec PR #35 · 1553ff9729ceb30f3ff03513cead45c5b7abd1d9 · 第一方CI记录

4. VAP #36：可追溯来源的英日双语报告

复查固定的53例证据，自动生成与来源对应的英语和日语报告。第一方CI通过37个测试方法、53例复查及报告重新生成一致性检查。自动报告不等于人工评审：人工评审保持NOT_PERFORMED，独立性及观测真实性保持NOT_ESTABLISHED。

变更及目标版本: vap-spec PR #36 · 3e621d522c4e5f536c850aa1e17821328680bfe6 · 第一方CI记录

5. VAP #37：要求映射与外部评审交接

将23项提案要求与27项关系对应：16项相关本地观测、11项部分相似例，不代表完全满足要求。PB-06、IR-01、IR-02、XR-01尚无对应实测例。新增程序和空白报告，区分保存证据复查、新执行及部署评估。这是文档映射，不是新增运行结果或外部评审结果；三个实验也不是已经整合的运行生命周期。

变更及目标版本: vap-spec PR #37 · 433f019513d991982fc6fb08bd4529808cc9f6a1

6. VAP #38：收集器停机与只读恢复

使用独立进程的回环收集器，将发送前持久记录、匹配的签名回执、最新读回和当前授权作为发送前提。确认响应丢失后，只读恢复不会重新发送旧请求，必须另有明确授权的新请求。41项测试、18个实际进程／网络场景及18项保存证据复查通过。元数据回执不是发送正文回执或独立观测；断电恢复能力、持续可用性及所有路径的绕过阻止尚未确立。

变更及目标版本: vap-spec PR #38 · 589d6b522c8d23261e9bfce1103784ac460c85ee · 第一方CI记录

7. VCP指南 #3：区分示例名称和实际SDK

明确历史指南中的“vcp-sdk 1.0.0”和vcp_sdk仅是示例名称。公开的veritaschain/vcp-sdk是面向VCP v1.2的0.1.0预发布离线核心，Python导入名为veritaschain_vcp。它不是指南所示日志器、Explorer客户端或符合性测试套件。

变更及目标版本: vcp-conformance-guide PR #3 · 0fc6d3d3ef75c92d9b8b7ee235a4f35119755057
