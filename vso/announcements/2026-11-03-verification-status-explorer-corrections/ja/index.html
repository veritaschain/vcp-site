VSO、検証状態の表記と公開Explorerを更新

2026年11月3日（JST）に23リポジトリでマージされた23件の修正を、一つのお知らせにまとめます。VAPの現行本文参照、公開ExplorerのGUI、両サイトのお知らせアーカイブを、取り込み済みの版に合わせて更新しました。

今回の範囲と検証状態

公開表記の訂正、限定した実装修正、自社による確認の記録です。VCP／VAPの完全適合、認証、本番適合、第三者による独立再現を成立させるものではありません。実験的拡張は未採択、独立再現は未成立です。PRに記載されたローカル試験、自社CI、今回のサイト公開確認、第三者自身による新規実行を区別します。

VAPの現行本文参照とハッシュ

VAP PR #45は、既に公開されていた契約件数の撤回注記を、過去のG-2の記述の直近にも追加し、処置を記録したものです。元の歴史的記述は保持されています。撤回された件数を検証済みの営業実績として扱わず、ゼロ件とも置き換えません。文書はv1.2.0 Draft 3のままで、規範要件の変更はありません。原文の訂正日付は11月2日、このサイトのお知らせはマージ後の11月3日です。

公開Explorer：入力されたハッシュのつながりと検証の限界を表示

GUI PR #22により、未知のTrace IDやイベントIDで無関係なデモ記録を返す動作を修正しました。検索・詳細取得を選択したTrace IDとデータモードに結び付け、新しい取得・中断・失敗時には古い結果を消します。Hash Chain画面はLINKS_MATCH、LINK_MISMATCH、INSUFFICIENT_DATA、INVALID_DATAを区別します。提示されたハッシュ文字列が一致しても、イベントハッシュの再計算、署名、信頼できる外部アンカー、完全性、起点の真正性を検証したことにはなりません。未検査・未成立の項目も残します。

認証処理・証明の境界・不明判定の修正

FIX・IBKR・Nasdaqの参照検証とtransparency backendは、認証されていない局所的な整合を完全検証として扱わないよう訂正しました。立証された不一致と、信頼の根拠が不明な状態を分けます。CAP-SRPは証明の結び付けと保存形式からの検証を修正。Cloudflare・TradingViewの例は取り込み・書き込みの前に設定済み認証情報を確認します。TradingViewはアンカー送信失敗時のバッチをメモリ内で保持しますが、再起動後の永続性を示すものではありません。supervision-nodeの例はAPI認可を要求し、未検証の証明結果を拒否します。これらのリポジトリ修正を、各サービスの本番公開や独立評価済みとは扱いません。

過去文書・保証表現・報告窓口の整理

VCP仕様、SDK／適合性ガイド、CAP文書、参照資料で、歴史的な状態、ライセンスの適用範囲、裏付けのない保証表現を整理しました。payoutデモは公開プレフィックスを署名検証として扱わず、GDPRデモのメール例は予約済みの例示用アドレスへ変更しています。vso-docsは非公開扱いの報告を現在のファイル一覧から撤去し、編集可能な認証書式を歴史資料と明示した書式へ置換しました。Git履歴やキャッシュから消去されたという意味ではありません。Explorer API #27はセキュリティ報告先の案内更新で、APIの検証動作変更ではありません。3言語のブローカー向けページは、分析計測に同意を必要とします。
