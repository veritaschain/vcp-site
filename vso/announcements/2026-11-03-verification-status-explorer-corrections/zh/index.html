VSO更新验证状态说明与公开Explorer

本公告汇总于2026年11月3日（JST）在23个仓库合并的23项更正，并将VAP当前正文引用、公开Explorer GUI及两个网站的公告归档与已合并版本对应。

范围与验证状态

这些是公开说明更正、有限的实现修复和自有验证记录，不代表VCP／VAP完全符合性、认证、生产适用性或第三方独立复现。实验性扩展仍未采纳，独立复现尚未成立。PR中报告的本地测试、自有CI、本次网站发布检查与第三方自行开展的新执行是不同记录。

当前VAP正文与哈希

VAP PR #45在历史G-2条目旁加入已发布的商业合同数量撤回说明及处置记录，保留原始历史文字。撤回的数字不作为已核实商业业绩，也不替换为零。文档仍为v1.2.0 Draft 3，规范要求未变。原文更正日期为11月2日，本网站公告日期为合并后的11月3日。

公开Explorer：明确哈希链接检查的范围

GUI PR #22修复未知Trace ID和事件ID回退到无关演示记录的问题。搜索、详情请求与所选Trace ID及数据模式绑定；新请求、中断或失败时清除旧结果。Hash Chain页面区分LINKS_MATCH、LINK_MISMATCH、INSUFFICIENT_DATA和INVALID_DATA。输入哈希字符串相等，不代表重新计算了事件哈希，也不建立签名、可信外部锚、完整性或起点真实性。未检查及未成立的项目仍单独显示。

身份验证、证明边界与不确定结果

FIX、IBKR、Nasdaq参考检查及transparency backend不再将未经认证的局部一致性当作完整验证。已证实的矛盾与信任依据不明明确区分。CAP-SRP修复证明绑定和序列化验证；Cloudflare和TradingView示例在接收或写入前检查配置的凭据。TradingView保留失败的内存锚定批次，但不证明重启后的持久性。supervision-node示例要求API授权并拒绝未验证的证明结果。仓库修复不意味着所有服务均已部署或独立评估。

历史资料、保证措辞与报告途径

VCP规范、SDK／符合性指南、CAP文档和参考材料澄清历史状态、许可证范围及缺乏依据的保证。payout演示不再把公开前缀称为签名验证，GDPR演示改用保留的示例邮件地址。vso-docs从当前目录撤下非公开报告，并将可编辑认证表单替换为明确标记的历史表单；不声称Git历史或缓存已经清除。Explorer API #27仅更新安全报告政策链接，不更改API验证行为。三种语言的经纪商页面要求分析计测同意。

如何理解测试记录

已合并GUI PR链接了最终审阅HEAD成功的自有CI，包括浏览器、子路径、无障碍和容器检查。本次静态发布另外运行GUI静态检查、生产构建及52项Node测试，并检查发布字节及电脑／手机显示。容器测试并不意味着GitHub Pages运行该容器或继承其nginx响应头。保留既有Evidence Demo API及固定输入，局部检查与完整证据状态仍然区分。其他PR包含自有CI及报告的本地测试，请分别查看下列原记录；不合计跨项目测试数量。
