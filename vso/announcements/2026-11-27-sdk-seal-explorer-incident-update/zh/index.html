VSO汇总SDK seal恢复、Explorer源代码更新与85条事件记录

本篇11月27日公告分四类汇总已合并的源代码和文档更新。CI结果属于列明的提交版本，与独立复现及公开部署证明分别处理。

实验性扩展与修正提案仍未采纳，独立第三方复现尚未成立。VAP规范引用与哈希不变，固定发行物、已签名数据和历史测试记录予以保留。

1．VCP SDK：批次策略检查与seal输出恢复

PR #25已合并至cb6a69ee5d5c6b666825aaf721c30f8f9ad45636。vcp seal在签名前检查全部输入事件是否使用同一个Header.PolicyID，并与显式--policy-id一致。它先暂存事件文件和AnchorRecord；第二次替换失败时，尝试恢复原事件输出。

两次替换并非一次原子事务。读取方必须等待成功结束。进程中断、回滚失败或清理警告可能需要检查保留的暂存和恢复文件；这不是针对任何中断的保证。

当前安装说明（英文）已固定到实现版本28d46e8491f6ff819f1cfe7c31895ed7ad7df3ff。历史v0.1.0标签cc6c468未变，也不含此修复。包元数据仍为0.1.0，说明使用--force-reinstall。发行说明的日期追加不等于新发行版。版本表（英文）保留11月26日快照，并追加27日信息。

2．Explorer：源代码维护与公开部署分开

API main 1f708ada55f12e609c343264201603ccc4f1568c中的#42在保留/health的同时增加/v1/health别名，并使用现有/v1速率限制。#36在保留UTF-8表单处理的情况下升级至Express 5.3.0；#39将Stylistic升级至6.0.1。

GUI #39、main 2c9868334ffd66888d28ab8a309d0c999fa82749调整了Vite 8.3.8、React插件6.3.0与组件测试构建，并显式声明esbuild 0.28.2。这是构建工具维护，不是新增密码学验证能力。

本次网站发布不重新部署公开Explorer。源代码构建、GitHub Pages发布成功或健康响应，均不能单独证明另行托管的API或公开GUI运行了这些版本。API与GUI的v1.0.0固定标签不变。

3．VCP事件检查CLI：将未解析Schema引用视为配置错误

PR #46、main 81513e5ddb600c20551b975e6c1e0ba126b67c54把无法解析的JSON Schema引用作为配置错误，退出码为2，并避免此时在标准输出留下部分批次判定。常规输入及文件错误的处理保持不变。

v1.2及基准说明还更新了欧盟业务时钟的引用。规范正文、Schema、评分规则及固定发行版均未改动。这是事件检查CLI修复，不是新增签名或Receipt的密码学验证。
