VCP Explorer API

历史接口设计示例 — 并非生产服务

搜索VCP示例事件，查看Explorer API返回的证明数据和证书JSON。

在GitHub查看API

概述

参考API从内存中的示例数据集读取交易事件。历史接口设计以VCP v1.0为基础。

证明数据

查看已保存的事件哈希、叶节点索引、审计路径和根哈希。

高级搜索

可按跟踪ID、交易品种、时间范围、事件类型或算法ID搜索示例事件。

事件证书JSON

API将已保存的事件和证明数据组合为一个JSON响应。

VCP模块结构

通过VCP-TRADE、VCP-RISK和VCP-GOV模块清晰分离关注点来组织事件数据。

纳秒精度

基于字符串的时间戳避免JavaScript 2^53限制,支持真正的纳秒级精度。

区块链锚定(计划中)

未来版本的VCP Explorer将支持将审计根锚定到以太坊以提供额外的可检测篡改性。

基础URL

http://localhost:3001/v1
运行以下示例前，请先在本地启动参考API。默认配置下，这些只读请求无需API密钥。 本地运行说明

认证

下文仅为历史接口设计示例。公开API没有认证中间件，不强制此API密钥请求头；不能视为访问控制保证。

HTTP头 
X-VCP-API-Key: <your_api_key>
安全: 不要在客户端代码中暴露API密钥。始终使用服务器端请求并妥善管理密钥。

API端点

GET /v1/events

通过符号、事件类型、trace_id、时间戳等搜索和过滤VCP事件。

查询参数

参数 类型 必填 说明 示例
symbol String 否 交易符号 XAUUSD, EURUSD
event_type String 否 事件类型名称 ORD, EXE, REJ
trace_id UUID v7 否 交易跟踪ID 01934e3a-6a1b...
start_time ISO8601 否 时间范围开始 2025-11-24T00:00:00Z
end_time ISO8601 否 时间范围结束 2025-11-24T23:59:59Z
limit Integer 否 最大结果数(1-500) 50 (默认)

curl --fail "http://localhost:3001/v1/events?symbol=XAUUSD&limit=1"

事件类型参考

代码 类型 说明 类别
1 SIG 信号/决策生成 交易
2 ORD 订单发送 交易
3 ACK 订单确认 交易
4 EXE 完全执行 交易
5 PRT 部分成交 交易
6 REJ 订单拒绝 交易
7 CXL 订单取消 交易
20 ALG 算法更新 治理

99 ERR 错误 系统

如何解读证明数据

证明接口返回演示数据。样例缺少树大小和经独立认证的检查点，因此不能确认Merkle树包含关系或外部锚定。

验证包含关系时，应使用事件、叶节点索引、树大小和审计路径重建根哈希，并与该树的可信检查点所认证的根哈希比较。只与同一响应中的根哈希比较，至多能检查数据的内部一致性。包含关系本身不能证明交易的真实性或实际执行情况。
