VCP Explorer API

過去のインターフェース設計例 — 本番提供サービスではありません

VCPのサンプルイベントを検索し、Explorer APIが返す証明データと証明書JSONを確認できます。

GitHubでAPIを見る

概要

リファレンスAPIはメモリ上のサンプル取引データを返します。過去のインターフェース設計はVCP v1.0に基づいています。

証明データ

保存済みのイベントハッシュ、葉の位置、監査パス、ルートを参照できます。

高度な検索

サンプルイベントをトレースID、銘柄、期間、イベント種別、アルゴリズムIDで検索できます。

イベント証明書JSON

保存済みのイベントと証明データを1つのJSONにまとめます。

VCPモジュール構造

VCP-TRADE、VCP-RISK、VCP-GOVモジュールによる明確な関心事の分離でイベントデータを整理。

ナノ秒精度

文字列ベースのタイムスタンプでJavaScriptの2^53制限を回避し、真のナノ秒レベルの精度をサポート。

ブロックチェーンアンカリング（計画中）

将来のVCP Explorerバージョンでは、追加の改ざん検知可能性のためEthereumへの監査ルートアンカリングをサポート予定。

以下は過去のインターフェース設計例です。公開APIには認証ミドルウェアがなく、このAPIキーヘッダーは強制されません。アクセス制御の保証として扱わないでください。

HTTPヘッダー 
X-VCP-API-Key: <your_api_key>
セキュリティ: クライアントサイドコードでAPIキーを公開しないでください。適切なキー管理を行い、常にサーバーサイドリクエストを使用してください。

APIエンドポイント

GET /v1/events

シンボル、イベントタイプ、trace_id、タイムスタンプなどでVCPイベントを検索およびフィルタリング。

クエリパラメータ

パラメータ 型 必須 説明 例
symbol String いいえ 取引シンボル XAUUSD, EURUSD
event_type String いいえ イベントタイプ名 ORD, EXE, REJ
trace_id UUID v7 いいえ トランザクショントレースID 01934e3a-6a1b...
start_time ISO8601 いいえ 時間範囲の開始 2025-11-24T00:00:00Z
end_time ISO8601 いいえ 時間範囲の終了 2025-11-24T23:59:59Z
limit Integer いいえ 最大結果数(1-500) 50 (デフォルト)

イベントタイプリファレンス

VCP仕様v1.0は、実装間の一貫性のために固定イベントタイプコードを定義しています:

コード タイプ 説明 カテゴリ
1 SIG シグナル/決定生成 取引
2 ORD 注文送信 取引
3 ACK 注文確認 取引
4 EXE 完全実行 取引
5 PRT 部分約定 取引
6 REJ 注文拒否 取引
7 CXL 注文キャンセル 取引
20 ALG アルゴリズム更新 ガバナンス
21 RSK リスクパラメータ変更 リスク
98 HBT ハートビート システム
99 ERR エラー システム

証明データの読み方

証明ルートが返すのはデモデータです。木のサイズと、独立して認証されたチェックポイントが欠けているため、このサンプルからMerkle木への包含や外部アンカリングは確認できません。

包含を検証するには、イベント、葉の位置、木のサイズ、監査パスから再計算したルートを、その木について信頼できるチェックポイントで認証されたルートと照合します。同じ応答に含まれるルートとの一致から分かるのは、入力間の整合性までです。包含の確認だけで、取引の真正性や実際の執行まで立証することはできません。
