VCP SDK：公開ソース・導入と検証の範囲

Python・TypeScript・MQL5のオフライン中核ライブラリ。配布状態、固定した導入版、検証できない事項を先に確認できます。

公開資料の確認日: 2026-11-14 · 解説・非規範

実験的拡張・修正案は未採択、第三者による独立再現は未成立です。自社CI、保存証拠の再検証、独立した環境での新規実行を区別します。研究上の一致は完全適合・本番安全性・認証を示しません。

公開されているのは開発ソース

現在のvcp-sdkは未リリースの開発ソースで、パッケージの版表示は0.1.0のままです。PyPI・npmには公開されていません。VCP SDK Specificationを実装するクラウド／Explorerクライアントとは別です。

VeritasChain株式会社による自社実装であり、外部実装、認証済み製品、独立した検証には数えません。VCP SDK: current source and pinned installation

固定コミットから導入する

READMEの導入手順は8eadded87e4f4e46d011835b2ba9a874b91c916dを指定しています。11月14日に確認したmainの説明と、この導入対象版は別です。後からmainへ加わった変更が、この固定版にも含まれるとは限りません。

歴史的なv0.1.0タグには後続修正が含まれません。「0.1.0」だけで報告せず、完全なコミットを記録してください。Pythonは3.10以降、TypeScriptはNode 20以降またはブラウザーバンドラーが前提です。VCP SDK: current source and pinned installationの導入節を利用してください。

三値の検証結果を読む

  • VALID：実施した確認が一致したこと。
  • INVALID：確認できた不一致や不正な入力。
  • INDETERMINATE：信頼する鍵、外部アンカー証拠、対応機能などが不足。合格ではありません。

集約の優先順位はINVALID、INDETERMINATE、VALIDです。外部アンカー証拠と検証機能が与えられなければ、完全なバッチ結果はINDETERMINATEのままです。

できることと限界

正規化ハッシュ、Merkle証明、Python／TypeScriptのEd25519署名などを扱います。MQL5側は機能範囲が異なり、同じ署名・検証機能を一式備えるとは限りません。

整数を正確な桁で処理する選択、RFC方式の木、根だけの署名範囲などはSDK implementation choices and verification limitsに記録された実装上の扱いです。VSOによる規範採択ではありません。

SDK自身は外部へ接続せず、鍵の実在人物への帰属、全行動の捕捉、判断の安全性、完全なJSON Schema適合を証明しません。公開ExplorerのSDK Explorer evidence demoも、実運用の監査結果ではありません。
