公開されているのは開発ソース

現在のvcp-sdkは未リリースの開発ソースで、パッケージの版表示は0.1.0のままです。PyPI・npmには公開されていません。VCP SDK Specificationを実装するクラウド／Explorerクライアントとは別です。

VeritasChain株式会社による自社実装であり、外部実装、認証済み製品、独立した検証には数えません。VCP SDK: current source and pinned installation

11月15日：mainの上書き防止修正と評価する版

SDK #18で、vcp sealの出力同士、入力証拠、鍵ファイルの衝突を事前に拒否する修正がmainへ入りました。相対パス・シンボリックリンク・ハードリンクを検査しますが、同時実行のロックや複数ファイルの原子的な保存を保証するものではありません。

今回の修正を評価するPython導入例は次の固定コミットを使います。新しいタグやPyPIパッケージではなく開発ソースです。

python -m pip install --force-reinstall "git+https://github.com/veritaschain/vcp-sdk.git@0832f1d84af9b130db6a17d36c343a8abd7002a8#subdirectory=python"

評価記録には完全なコミット、入力、信頼設定、依存環境を残してください。従来の固定導入版・タグは変更していません。

更新内容・対象版・限界を読む · SDK #18

固定コミットから導入する

vcp sealの出力先衝突チェックを含む版を導入するには、0832f1d84af9b130db6a17d36c343a8abd7002a8を指定してください。Pythonは上記のコマンドを使用し、TypeScriptのビルドやMQL5のコピーも同じコミットで行います。以前の導入版と過去のv0.1.0タグには、このチェックがありません。

評価記録には完全なコミットを残してください。パッケージの版表示だけでは導入したコードを特定できません。Pythonは3.10以降、TypeScriptのビルドはNode 20以降が必要です。

三値の検証結果を読む

  • VALID：実施した確認が一致したこと。
  • INVALID：確認できた不一致や不正な入力。
  • INDETERMINATE：信頼する鍵、外部アンカー証拠、対応機能などが不足。合格ではありません。

集約の優先順位はINVALID、INDETERMINATE、VALIDです。外部アンカー証拠と検証機能が与えられなければ、完全なバッチ結果はINDETERMINATEのままです。

できることと限界

正規化ハッシュ、Merkle証明、Python／TypeScriptのEd25519署名などを扱います。MQL5側は機能範囲が異なり、同じ署名・検証機能を一式備えるとは限りません。

整数を正確な桁で処理する選択、RFC方式の木、根だけの署名範囲などはSDK implementation choices and verification limitsに記録された実装上の扱いです。VSOによる規範採択ではありません。

SDK自身は外部へ接続せず、鍵の実在人物への帰属、全行動の捕捉、判断の安全性、完全なJSON Schema適合を証明しません。公開ExplorerのSDK Explorer evidence demoも、実運用の監査結果ではありません。
